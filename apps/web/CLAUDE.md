## UI library

This app uses `forge-ui` (vendored from `vendor/forge-ui-0.2.0.tgz`) for all UI components. Before writing or modifying any UI code, read `node_modules/forge-ui/llms.txt` — it documents every exported component's props, variants, and usage examples. Don't guess prop names from training data; this library's API may differ.
